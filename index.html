Origami Simulator

This open-source tool simulates how any origami crease pattern will fold. It uses GPU computation to solve for the geometry of the folded shape.

Instructions:

  • Adjust the Fold Percent slider to control folding
  • Drag to rotate, scroll to zoom
  • Import your own patterns or try the examples
